# System Docs

This folder holds the internal system layer derived from the active Vision spec in [../vision/](../vision/README.md).

## What Belongs Here

- architecture outlines
- module definitions
- data model notes
- API and interface boundaries
- clarity on what is real versus mocked for the current phase

## What Does Not Belong Here

- product direction changes that belong in [../vision/](../vision/README.md)
- outward-facing demo narrative that belongs in [../demo/](../demo/README.md)
- unfinished exploratory notes that belong in [../drafts/](../drafts/README.md)

## Relationship To Other Folders

- System exists to support the active Vision spec.
- System should make clear what is needed to support the Demo layer.
- If internal changes imply a change in product definition, update Vision first.
