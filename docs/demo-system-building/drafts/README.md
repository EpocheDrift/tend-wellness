# Drafts

This folder is a temporary holding area for unfinished thinking related to the Demo / System Building docs.

## What Belongs Here

- incomplete notes
- rough proposals
- migration staging from Notion
- versioning discussions
- partially formed questions that are not yet ready for Vision, Demo, or System

## What Does Not Belong Here

- the active working Vision spec
- finalized demo docs
- stable system definitions being used for execution

## Relationship To Other Folders

- Drafts can later be promoted into [../vision/](../vision/README.md), [../demo/](../demo/README.md), or [../system/](../system/README.md).
- Drafts are allowed to stay unfinished.
- Drafts should be refined, promoted, archived, or replaced as the structure matures.
