# Demo Docs

This folder holds the outward-facing demo layer derived from the active Vision spec in [../vision/](../vision/README.md).

## What Belongs Here

- demo narrative
- demo flow
- demo script
- demo readiness checklist

## What Does Not Belong Here

- frozen product strategy beyond what the active Vision spec defines
- internal architecture details that belong in [../system/](../system/README.md)
- rough ideation or partial notes that belong in [../drafts/](../drafts/README.md)

## Relationship To Other Folders

- Demo should reflect the active Vision spec, not invent a separate product direction.
- Demo should stay aligned with what the System layer can actually support or intentionally mock.
- If the narrative changes because the product direction changes, update Vision first.
