# Vision Docs

This folder holds versioned Vision specs that define what the current phase is trying to build and prove.

## What Belongs Here

- frozen working specs
- explicit versioned documents
- the currently active phase definition
- scope, proof goals, non-goals, and exit conditions

## What Does Not Belong Here

- demo presentation notes that belong in [../demo/](../demo/README.md)
- implementation detail that belongs in [../system/](../system/README.md)
- unfinished ideation that belongs in [../drafts/](../drafts/README.md)

## Relationship To Other Folders

- Vision is the source for Demo and System.
- Demo translates Vision into a showable experience.
- System translates Vision into buildable internal structure.
- Drafts may inform a future version, but do not change the active Vision spec automatically.
