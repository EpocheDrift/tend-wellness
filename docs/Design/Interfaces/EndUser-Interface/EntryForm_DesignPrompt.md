Design a minimal booking inquiry form to be embedded as a Squarespace code block. This is NOT a standalone page — it sits inside an existing warm, organic wellness website with a warm off-white background (#ede8de), dark serif typography, and deep olive green buttons.

The form should feel like it belongs to the page, not like a foreign widget.

---

VISUAL DIRECTION
- Background: match the site's warm off-white (#ede8de), no white card box
- No border, no drop shadow, no card container — the form should feel flush with the page
- Font: serif, dark (#2c2c2c), consistent with the surrounding site
- Input fields: minimal underline or very light border style, no boxy outlines
- Submit button: deep olive green (#2d3d2e), pill/capsule shape, white label text — matching the site's existing button style
- Liquid Glass: do NOT apply here — this form should feel like part of the page, not a floating UI element

---

FORM STRUCTURE

Label above the form (small, muted):
"Book a Session"

Fields (in order):
1. Name — single line text input
2. Email — single line email input  
3. "Tell me a bit about what you're looking for" — multiline textarea, 3–4 rows, no resize handle

Submit button:
- Label: "Send"
- Pill shape, full width or comfortable fixed width
- Deep olive green (#2d3d2e), white text

---

STATES TO DESIGN

State 1 — Default (empty form, ready to fill)
State 2 — Post-submit confirmation (inline, no page redirect)
  - Hide the form fields
  - Show a single short message: "Got it — I'll take a look and follow up shortly."
  - Same typographic style as the form, no icons, no box

---

CONSTRAINTS
- No Squarespace branding
- No progress indicators
- No required field asterisks
- No placeholder text that disappears — use floating labels or static labels above fields
- Mobile-responsive layout
- Spacing should feel generous and calm, not tight
